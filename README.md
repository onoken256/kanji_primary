# 学年別 漢字よみドリル

小学校の学年別漢字配当表（1026字）にもとづいて、漢字の読みを出題するブラウザアプリです。
ビルドすると外部依存のない1ファイルのHTMLになります（フォントのみ Google Fonts を参照）。

## 特徴

- **学年別の出題** — 1〜6年を選んで出題。「この学年だけ」「この学年まで（累計）」を切替可能
- **2つの出題モード**
  - 漢字ひとつ … 原稿用紙のマス目に1字を表示し、音読み／訓読みを答える
  - 短文の読み … 短文中の語の読みを答える
- **他学年の漢字もそのまま漢字で表示** — 選んだ学年より上の漢字にだけ自動でふりがな（ルビ）が付く。
  ふりがなは「上の学年だけ／ぜんぶ／なし」で切替可能
- 4択／キーボード入力の切替、10問1セット、まちがえた問題だけの復習
- ライト／ダークの手動切替（OSがダークでもライト表示にできる）
- タブレット対応（タップ領域の拡大、ソフトキーボード表示時のレイアウト圧縮）

## 使い方

`dist/app.html`（または `dist/preview.html`）をブラウザで開くだけで動きます。

## 収録データ

| 学年 | 配当漢字 | 短文の出題語 |
|---|---|---|
| 1年 | 80字 | 304語 |
| 2年 | 160字 | 501語 |
| 3年 | 200字 | 437語 |
| 4年 | 202字 | 273語 |
| 5年 | 193字 | 224語 |
| 6年 | 191字 | 211語 |

短文は390本。**各学年の配当漢字が1字残らず出題対象に含まれる**ことを `build.py` で検証しています。

## ビルド

```bash
# 読みデータ（KANJIDIC2）を取得
curl -O http://www.edrdg.org/kanjidic/kanjidic2.xml.gz

# data/s1〜s6.txt を解析 → data.js を生成 → dist/ に1ファイルHTMLを書き出す
python3 build.py --emit
```

`build.py` は実行のたびに学年別カバレッジを表示します。未カバーの漢字があれば、その学年の
`data/s*.txt` に短文を足してください。

### 短文の書き方

`data/s1.txt` 〜 `s6.txt` に、1行1文で書きます。**文中の漢字にはすべて `《》` で読みを付けます**
（読みが無い漢字が残っていると `build.py` がエラーとして報告します）。

```
学校《がっこう》の先生《せんせい》が、大《おお》きな声《こえ》で本《ほん》を読《よ》む。
```

出題語はアプリが自動で選びます（選んだ学年の漢字を含み、それ以下の漢字だけで構成された語）。
ファイルを学年別に分けているのは書きやすさのためで、出題時は全ファイルを1つのプールとして扱います。
同じ文が、1年生にはルビだらけで、6年生にはほぼルビなしで表示されます。

### 検査スクリプト

```bash
python3 verify.py    # 語の読みが構成漢字の読み（連濁・促音を許容）で説明できるか
python3 verify2.py   # 1字語の読みと送り仮名の整合（例: 三《さん》つ のような誤りを検出）
```

どちらも「要確認」の候補を出すだけで、熟字訓（今日・部屋・景色など）や地名は正常に検出されます。
目視で確認してください。

## ファイル構成

```
build.py          短文の解析・カバレッジ検証・data.js 生成・dist ビルド
verify.py         読みの検査（構成漢字との整合）
verify2.py        送り仮名の検査
data/s1〜s6.txt   短文のソース（ルビ付き）
data.js           生成物：漢字1026字の学年・音訓 ＋ 短文390本
src/app.html      アプリ本体（__KANJI_DATA__ に data.js が埋め込まれる）
dist/app.html     生成物：配布用の1ファイルHTML
```

## 出典とライセンス

- **配当漢字**：文部科学省「学年別漢字配当表」（小学校学習指導要領・平成29年告示／1026字）に準拠。
  4年に都道府県名の漢字20字を含む現行の配当です。旧課程（平成20年告示）とは一部の学年が異なります。
- **読みデータ**：[KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project)
  （Electronic Dictionary Research and Development Group, **CC BY-SA 4.0**）。
  生成物である `data.js` の音訓データはこのライセンスの派生物にあたるため、再配布の際は
  EDRDG への帰属表示と同一ライセンスでの提供が必要です（アプリのフッターに明記しています）。
- **短文390本**：このアプリのために書き下ろしたオリジナルです。
- アプリのコード自体のライセンスは未設定です。公開方針が決まったら `LICENSE` を追加してください。
